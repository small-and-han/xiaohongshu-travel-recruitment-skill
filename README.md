# Xiaohongshu Travel Recruitment Skill v3

这是一个用于 **Codex / ChatGPT Skill** 的小红书旅行招募组图自动化工作流。

它可以根据用户提供的 **路线信息、地点名称、旅行图片、可选风格要求**，自动补全缺失资料，并生成一组适合小红书发布的旅行招募图片。

## 核心能力

- 根据路线信息和图片，自动生成小红书旅行招募组图
- 信息缺失时，优先联网搜索公开资料补全
- 默认自动执行，不反复要求用户确认大纲
- 固定输出 4 张独立竖版 3:4 图片
- 不生成四宫格，不把 4 张图拼成一张
- 支持风格模块化，后期可方便修改视觉风格
- 第 2 张固定为 **C 版路线流动式行程节奏图**

## 固定输出结构

最终输出必须是 4 张独立图片：

1. **首图**  
   用于吸引点击，建立目的地氛围和招募感。

2. **行程节奏图**  
   使用路线流动式设计，重点展示一天或多日行程中“什么时间到哪里、玩什么”。

3. **亮点展示图**  
   提炼 3–5 个路线亮点，制造体验欲。

4. **注意事项图**  
   展示装备、安全、天气、适合人群等提醒，建立信任感。

## 文件说明

### `SKILL.md`

Skill 入口文件，定义：

- 什么时候启用 Skill
- 输入和输出规则
- 自动执行规则
- 信息缺失时的处理方式
- 4 张独立图片的硬性要求
- 禁止事项

### `references/workflow.md`

定义自动化工作流，包括：

- 如何读取用户输入
- 如何判断信息完整度
- 什么时候联网搜索
- 哪些信息可以补全
- 哪些信息不能编造
- 如何把公开资料转化为小红书招募语言
- 如何分配用户上传图片

### `references/style-profiles.md`

定义可替换视觉风格。

当前内置 4 套风格：

1. 电影感轻旅招募风
2. 清爽旅行攻略风
3. 旅行手账拼贴风
4. 高级户外杂志风

后期主要通过修改这个文件来调整生成图片的视觉风格。

### `references/page-structure.md`

定义 4 张图的固定页面结构和功能分工。

重点约束：

- 首图重氛围
- 第 2 张必须是路线流动式行程节奏图
- 亮点图重体验欲
- 注意事项图重清晰可信

### `references/prompt-rules.md`

定义图片生成提示词规则。

重点约束：

- 每张图独立生成
- 不生成四宫格
- 不生成合集图
- 竖版 3:4
- 中文字尽量少
- 大标题优先
- 避免密集小字和乱码

## 使用方式

在 Codex 或支持 Skill 的环境中安装后，可以这样使用：

```txt
使用 xiaohongshu-travel-recruitment-skill
地点：开阳香火岩瀑布
出发地：贵阳
图片已上传
帮我做一组小红书旅行招募图
```

也可以提供更完整的信息：

```txt
使用 xiaohongshu-travel-recruitment-skill
路线：团山溯溪一日游
出发地：贵阳
玩法：溯溪踩水、高台跳水、水仗嬉戏
风格：电影感轻旅招募风
图片已上传
```

也支持指定风格：

```txt
使用 xiaohongshu-travel-recruitment-skill
地点：罗甸大小井
风格：旅行手账拼贴风
图片已上传
```

或者参考上传图片风格：

```txt
使用 xiaohongshu-travel-recruitment-skill
参考我上传的第一张图风格
整体更清爽，文字少一点，不要手账贴纸
地点：紫江地缝
图片已上传
```

## 风格修改方法

后期想修改图片风格，优先修改：

```txt
references/style-profiles.md
```

例如，你可以新增一套风格：

```md
# Style Profile E: blue_night_recruitment

## 中文名称
蓝调夜景招募风

## 适合场景
夜景、露营、音乐节、星空、烟火、草原活动。

## 整体气质
深蓝色电影感，安静、浪漫、夜晚氛围强。

## 色彩
深蓝、冷白、暗紫、少量暖橙点缀。

## 字体
中文主标题使用高级宋体，英文使用小号大写 serif。

## 排版
大图背景、暗角、少量标签、底部信息栏。

## 禁止
不要霓虹过度、不要电商促销感、不要高饱和撞色。
```

然后在使用时指定：

```txt
风格：蓝调夜景招募风
```

## 自动搜索与信息边界

当用户信息不完整时，Skill 会优先搜索公开资料，补全：

- 目的地位置
- 大致车程
- 自然特征
- 核心看点
- 常见玩法
- 装备建议
- 安全注意事项
- 官方公开限制

但不能编造以下信息：

- 价格
- 具体集合点
- 成团人数
- 报名方式
- 保险信息
- 领队人数
- 商家承诺
- 官方合作资质

这些信息缺失时，应使用：

- 详询客服
- 以出行通知为准
- 参考行程
- 小团出行
- 联系客服咨询

## 注意事项

这个 Skill 的目标是生成旅行招募组图，不是生成普通攻略长图。

必须始终遵守：

- 4 张独立图片
- 每张只讲一个核心信息
- 第 2 张必须是路线流动式行程节奏图
- 风格可以变，但页面任务不能变
- 自动执行，不默认反复确认
- 不生成四宫格
