# Style Profiles

本文件定义可替换的视觉风格模块。

风格模块只控制视觉表现，不改变 4 张图的页面任务。

无论使用哪种风格，仍然必须输出：

1. 首图
2. 行程节奏图
3. 亮点展示图
4. 注意事项图

---

# Default Style

默认风格：`cinematic_light_travel`

中文名称：**电影感轻旅招募风**

---

# Style Selection Rules

如果用户明确指定风格，优先使用用户指定风格。

如果用户上传参考图并要求参考，优先提取参考图风格。

如果用户没有指定风格，使用默认风格。

用户可以使用以下表达切换风格：

- 风格：电影感轻旅招募风
- 风格：清爽旅行攻略风
- 风格：旅行手账拼贴风
- 风格：高级户外杂志风
- 参考我上传的图片风格
- 更清爽一点
- 更高级一点
- 更手账一点
- 更像旅行杂志

# Style Profile A: cinematic_light_travel

## 中文名称

电影感轻旅招募风

## 适合场景

雪山、草原、瀑布、峡谷、溯溪、洞穴、露营、轻徒步、旅行招募、户外活动。

## 整体气质

真实照片主视觉，电影海报感，低饱和，高级、克制、有品牌感。

## 色彩

以照片主色为基础，整体低饱和。常用色调包括：深蓝、墨绿、岩石灰、冷白、暖橙点缀、米白文字。强调色只能小面积使用。

## 字体

- 中文主标题：高级宋体 / 明朝体 / 现代衬线中文
- 英文辅助：小号大写 serif
- 正文：轻量无衬线

## 排版

- 大标题压图
- 电影海报式层级
- 细线分割
- 小号英文辅助
- 低透明信息面板
- 底部标签栏
- 画面有呼吸感

## 装饰

- 细线
- 小号英文
- 轻微暗角
- 轻遮罩
- 极简路径线
- 少量标签

## 禁止

- 不要电商促销风
- 不要粗黑描边字
- 不要卡通贴纸
- 不要高饱和撞色
- 不要密集小字

## 禁止

# Style Override Rules

如果用户本次提供具体风格描述，应优先覆盖当前风格。

例如用户说：“参考第一张图，蓝绿色、电影感、文字少一点、不要手账贴纸。”

则执行：

- 使用电影感轻旅招募风作为基础；
- 色调偏蓝绿；
- 减少文字；
- 禁止手账贴纸；
- 仍然生成 4 张独立图片。

用户的风格要求只覆盖视觉表现，不改变固定页面结构。
